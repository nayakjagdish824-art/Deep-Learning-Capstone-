# Deep Learning Capstone Project

This project demonstrates the implementation of core deep learning architectures across different problem domains using TensorFlow/Keras.

## Overview
The project consists of three experiments:

1. Feedforward Neural Network (FNN)
   - Task: Income classification
   - Dataset: UCI Adult Dataset
   - Accuracy: 85%

2. Convolutional Neural Network (CNN)
   - Task: Image classification
   - Dataset: Fashion-MNIST
   - Accuracy: 90%

3. Long Short-Term Memory (LSTM)
   - Task: Temperature forecasting
   - Dataset: Delhi Climate Dataset
   - MSE: 0.041
